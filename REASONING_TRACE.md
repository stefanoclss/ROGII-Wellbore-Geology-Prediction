### Machine-Verifiable Transfer Assumptions (For Weaker Models)
- **`require_1d_reference_curve`** (`hard_blocker`, `has_reference_curve` `bool_true` `True`): The 12-channel 2D alignment image encodes similarity between observed sequence logs and a paired 1D reference curve at every candidate vertical offset. → *If violated*: DIVERGE_DO_NOT_COPY 2D reference-alignment CNN; instead explore 1D Temporal ConvNet (TCN) / BiGRU sequence encoders or autoregressive residual GBDTs directly on sequence dynamics.
- **`single_vs_multi_channel_sensor`** (`adapt_required`, `sensor_channel_count` `eq` `1`): Channels 0-3 assume one primary scalar sensor log (e.g., GR) compared to a 1D reference log. → *If violated*: ADAPT 2D input stem: if sensor_channel_count > 1 (e.g., multi-sensor telemetry/IMU/multi-log), stack per-channel similarity/bandpass maps or replace manual similarity with a learned 1D-to-2D cross-attention/outer-product similarity encoder.
- **`sensor_missingness_gap_handling`** (`adapt_required`, `sensor_missing_rate` `lte` `0.65`): Linear interpolation across long sensor NaN gaps hallucinates false peaks (`sp4.5` degraded from 9.70 -> 11.23 RMSE); NaN-masked likelihood + explicit validity mask channel are essential when missing rate > 5%. → *If violated*: ADAPT sensor likelihood & masking: if missing rate > 65%, down-weight sensor similarity and rely primarily on coupled kinematics/spatial geometry; if missing rate == 0%, simplify mask channel and test sharper sensor noise sigma.
- **`vertical_window_coordinate_frame`** (`adapt_required`, `target_anchor_span_p99` `lte` `72.0`): On ROGII 99.6% of rows satisfy |TVT - last_TVT| <= 72 ft (while |U - last_U| exceeded 72 ft on 52.5% of rows), so indexing the 2D CNN vertically in (y - last_y) prevented clipping. → *If violated*: ADAPT vertical grid & coordinate frame: empirically compare p99(|y - last_y|) vs p99(|U - last_U|) on training folds before training the 2D CNN; choose the tighter frame and set half_span >= 1.2 * p99.
- **`spatial_neighbor_surface_availability`** (`advisory`, `has_train_only_surfaces` `bool_true` `True`): Spatial Plane-KNN & Dense IDW exploit neighbor entities' auxiliary surfaces gated by distance + prefix RMSE (high error standalone 23.8-37.8, helpful only when distance-gated). → *If violated*: ADAPT by omitting channel 7 (spatial surface stripe) and spatial consensus terms cleanly when spatial coordinates or train-only surfaces do not exist.
- **`disjoint_entity_group_validation`** (`adapt_required`, `disjoint_entity_groups` `bool_true` `True`): Disjoint GroupKFold entities require entity-grouped inner Optuna/early-stopping splits, excluding entity_id from categorical features, order-preserving sampling, and jump-safe SavGol. → *If violated*: ADAPT CV & encoding: if entities overlap across train/test, switch to Stratified/Time split and evaluate entity OOF target encoding.

### Copy vs. Adapt vs. Diverge Rules
- DO NOT blindly copy the 2D reference-alignment CNN if the new problem lacks a 1D reference curve — diverge to 1D TCN/BiGRU/Transformer or multi-scale GBDTs.
- ALWAYS inspect sensor channel count, calibration drift, and NaN gap distribution before building 2D similarity channels; adapt multi-channel sensors rather than forcing single-channel formulas.
- ALWAYS measure p99 target excursion in both raw target space and coupled-invariant space before fixing a 2D vertical window span.
- NEVER copy postprocessing smoothers or target encodings without verifying GroupKFold entity disjointness and sequential row ordering.
